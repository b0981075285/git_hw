## 一、簡答題

### 1. 終端機迷路

你不確定目前位於哪個資料夾，應先使用什麼指令？ pwd

### 2. 查看最新錯誤

系統日誌有數千行，你只想看最後 20 行，應使用什麼指令？ tail -n 20

### 3. 長文件閱讀

你要閱讀一份很長的文字檔，並希望能上下翻頁、搜尋關鍵字，應使用 `cat`、`less` 還是 `tail`？為什麼？ less
用less進入後可用「上下方向鍵」捲動，按 / 再輸入關鍵字可搜尋，按 q 離開。

### 4. 尋找錯誤訊息

你要在 `app.log` 中找出所有包含 `ERROR` 的行，應使用什麼指令？grep `ERROR`

如果還要顯示行號，需要搭配哪個參數？-n

### 5. 團隊檔案權限

檔案需求如下：

- 擁有者可讀、可寫
- 同群組只能讀
- 其他人完全沒有權限

應使用哪個權限數字？chmod 640

### 6. 打包資料夾

你要把整個 `project` 資料夾打包並以 gzip 壓縮成一個 `.tar.gz` 檔案，應使用哪個工具？tar

如果只想查看壓縮檔內容、不解開，`tar` 應使用代表「查看」的哪個參數？-tzf

### 7. 遠端服務故障

你需要依序確認：

1. 主機是否能連到
2. 網站服務是否有回應
3. 是否能遠端登入

這三個階段分別應使用哪些指令？ping 、 curl 、 ssh
### 8. SSH 斷線仍要繼續執行

某個程式需要執行八小時，SSH 斷線後也不能停止，而且執行期間不需要互動。適合使用 `nohup` 還是 `tmux`？nohup

若日後還要回到原本的終端機畫面繼續操作，又應選哪一個？tmux
### 9. 磁碟空間不足

主機出現 `No space left on device`：

1. 應先用什麼指令找出快滿的分區？df
2. 再用什麼指令找出占空間的資料夾？du
3. 若要搜尋大於 500MB 的檔案，應使用什麼指令？find / -type f -size +500M
### 10. 服務無法啟動

`nginx` 無法啟動。請說明你會依序使用哪些指令或工具來：

1. 查看服務狀態         sudo systemctl status
2. 查看更完整的服務日誌 sudo journalctl
3. 修正後重新啟動服務   sudo systemctl restart
4. 確認 HTTP 是否恢復   curl

## 二、選擇題

### 11. 顯示隱藏檔案

哪個指令可以顯示目前目錄中包含隱藏檔的詳細資訊？B

- A. `ls`
- B. `ls -la`
- C. `pwd -a`
- D. `cat -la`

### 12. 保留原檔並產生副本

你想保留原始檔案，同時產生一份副本，應使用：C

- A. `mv`
- B. `rm`
- C. `cp`
- D. `touch`

### 13. 追加日誌

`app.log` 已經有重要內容。要將新訊息加在檔案結尾，應使用：B

- A. `echo "訊息" > app.log`
- B. `echo "訊息" >> app.log`
- C. `echo "訊息" < app.log`
- D. `rm app.log`

### 14. 加入群組

要把 `alice` 加入 `project-team`，又不能移除她原本所屬的群組，正確指令是：B

- A. `usermod -G project-team alice`
- B. `usermod -aG project-team alice`
- C. `groupadd alice project-team`
- D. `chmod project-team alice`

### 15. 權限判讀

權限 `-rwxr-x---` 代表：A

- A. 擁有者可讀寫執行，群組可讀與執行，其他人無權限
- B. 所有人都可讀寫執行
- C. 擁有者只能讀，群組可寫，其他人可執行
- D. 這是一個所有人都能進入的目錄

### 16. Shell 變數

哪個是正確的 Bash 變數宣告？B

- A. `name = alice`
- B. `name=alice`
- C. `$name=alice`
- D. `set name alice`

### 17. 引號差異

假設 `name=alice`，哪個指令會輸出 `Hello alice`？D

- A. `echo 'Hello $name'`
- B. `echo "Hello $name"`
- C. `echo Hello = name`
- D. `echo 'Hello ${name}'`

### 18. Cron 排程

每天凌晨 2:30 執行一次，正確的 Cron 時間欄位是：B

- A. `2 30 * * *`
- B. `30 2 * * *`
- C. `* * 2 30 *`
- D. `30 * 2 * *`

### 19. 網路設定持久化

在 Ubuntu 24.04 Server 上，要讓固定 IP 重開機後仍然存在，較正確的方式是：B

- A. 只執行 `ip addr add`
- B. 修改 `/etc/netplan/*.yaml` 並套用設定
- C. 修改一般文字檔
- D. 每次開機後手動執行 `ping`

### 20. 結束行程

某個程式正常運作，但現在需要停止。第一選擇應該是：A

- A. `kill <PID>`
- B. `kill -9 <PID>`
- C. 直接關閉主機
- D. 刪除程式檔案

### 21. Systemd 服務

下列哪個敘述正確？C

- A. `start` 只設定下次開機啟動
- B. `enable` 一定會立即啟動服務
- C. `start` 立即啟動；`enable` 設定開機自動啟動
- D. `stop` 會解除安裝服務

### 22. 版本捷徑

你希望 `/opt/app/current` 能切換指向不同版本的資料夾，應使用：B

- A. Hard Link
- B. Symbolic Link
- C. `gzip`
- D. `chmod`

## 三、是非題

### 23.

`rm` 刪除的檔案通常會先進入 Linux 資源回收桶，因此很容易復原。

- [ ] 正確

### 24.

`cd ..` 代表移動到上一層目錄。

- [v] 正確
- [ ] 錯誤

### 25.

`>` 會覆蓋原有內容，`>>` 會將內容附加到檔案結尾。

- [v] 正確
- [ ] 錯誤

### 26.

執行 `ping` 成功，就能保證對方的網站服務一定正常。

- [ ] 正確
- [v] 錯誤

### 27.

SSH 私鑰可以上傳到 GitHub，因為真正需要保密的是公鑰。

- [ ] 正確
- [v] 錯誤

### 28.

Cron 執行時的環境可能和一般登入終端機不同，因此腳本和重要指令最好使用絕對路徑。

- [v] 正確
- [ ] 錯誤

### 29.

`kill -9` 會讓程式有充分時間存檔並清理資源，所以應優先使用。

- [ ] 正確
- [v] 錯誤

### 30.

`df` 適合查看各分區的整體使用率；`du` 適合分析個別資料夾的空間占用。

- [v] 正確
- [ ] 錯誤

### 31.

`systemctl enable nginx` 的主要作用是設定 nginx 開機自動啟動。

- [v] 正確
- [ ] 錯誤

### 32.

刪除 Symbolic Link 指向的原始檔案後，該連結可能會變成失效連結。

- [v] 正確
- [ ] 錯誤

### 33.

Hard Link 與原檔名指向同一個 inode，因此刪除其中一個檔名後，另一個通常仍能讀取資料。

- [v] 正確
- [ ] 錯誤
